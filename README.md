# repoviz

> Visual interactive explorer for kit repositories.

**repoviz** analyzes any "kit" repository — Claude Code workspaces, spec-kit projects, agent repos — and renders an interactive visualization in your local browser showing how all files relate to each other.

## What it shows

- **Agents** — what each agent does, what files it reads, edits, or creates
- **Skills** — what each skill does and which files it invokes or references
- **Hooks** — what triggers them and what they affect
- **Context files** — how they feed into agents and workflows
- **File relationships** — the full dependency graph, interactive and explorable
